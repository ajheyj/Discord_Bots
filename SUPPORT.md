# Support and contact

## Hosted-bot help

Contact the server owner or a moderator privately and ask them to put you in touch with the operator of the affected bot. The repository maintainer is [ajheyj](https://github.com/ajheyj). An independently hosted copy may have a different operator; the repository maintainer cannot inspect or delete that host's records.

For ordinary leaderboard questions, /submission-result shows your latest completed result, /rank shows your standings, and /leaderboard browses rankings. A missing stat is different from an unchanged best. Include the exact recognition note when reporting an OCR problem. A moderator can correct an incorrect score; that correction does not ban future submissions.

## Privacy requests — send privately

Ask the server owner/moderators for a **bot privacy request** to reach the operator. Provide:

- The bot name and server where it operates.
- Your Discord account ID, preferably by contacting us from that account.
- Whether you want access, a correction, deletion, or another privacy-related action.
- Relevant submission links/IDs if you already have them; these are helpful, not a requirement to request help.

Do not post this information or private screenshots in a public GitHub issue. Never provide a password, token, identity document or payment information. If a moderator is the subject of the concern, ask the server owner for a direct private route to the operator.

The bot has no full privacy-deletion slash command. Removing scores or deleting an original message does not remove all retained copies. See [PRIVACY.md](PRIVACY.md) for the scope of operator handling. The operator must publish a working direct private contact route in the server/application information and keep it available; the general routing description here is not a substitute for maintaining that contact.

## Software bugs and improvements

Use [GitHub issues](https://github.com/ajheyj/Discord_Bots/issues) for nonsensitive software bugs and suggestions if issues are enabled. Include the bot name, software version/commit, operating system, expected/actual result and sanitized error text. Send sensitive examples privately, not as issue attachments.

For leaderboard OCR reports, tell us whether the bot said “Not read” or “No change.” A reproducible image can help, but share it privately and remove irrelevant personal material. Do not use someone else's submission without authority.

Security vulnerabilities use the private process in [SECURITY.md](SECURITY.md). There is no guaranteed response time or 24/7 support service; privacy and incident obligations still apply.
